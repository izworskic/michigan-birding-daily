# Michigan Birding Daily publisher resilience

The scheduled publisher prefers the authorized Fall Color credential if configured as `ANTHROPIC_API_KEY_FALL_COLOR` or `FALL_ANTHROPIC_API_KEY`, then the existing `ANTHROPIC_API_KEY`. Retry only on explicit authentication rejection; no model retry after other failures. A validated, source-based county article is generated from dated, public eBird observations when the provider is unavailable or its output fails structure checks. Unknown counts are not converted to one. Private, invalid, future and old observations are excluded. No current observations means no new article, rather than a fabricated report. The previous edition remains available. Fallback editions carry generation mode and reason; source failures remain visible. NWS forecast freshness is bounded and missing weather is explicitly stated. Existing storage and schedules are retained. The owner must configure the authorized credential in the Vercel project directly; keys cannot be copied through this repository. A bounded state lock prevents concurrent triggers, and the publisher does not proceed on failed state reads. Existing URLs and Person identity are unchanged.
